# 编辑已安装技能的 SKILL.md

说明详情抽屉如何就地编辑本地已安装技能的 `SKILL.md`，以及编辑能力的边界。

English: [editing-skills.md](./editing-skills.md)

## 适用范围

只有**已安装**的技能可以编辑。技能文件位于 `~/.agents/skills/<name>/SKILL.md`
（被停用时位于 `disabled-skills/<name>/SKILL.md`）。商店里未安装的条目是远端镜像
内容，本地没有可写文件，因此编辑入口只在已安装表面提供（my-skills 与 local-skills
列表，以及商店中标记为已安装的分区）。

正文区以一条“承载文件名”的分隔线开头：线沿内缩宽度贯穿，居中的 `SKILL.md` 标签与右端
的内容操作都坐在面板底色上、把线断开——是一条真正的分隔线，而非第二条标题栏。该操作在
两种形态下位置不变——查看态显示编辑图标，编辑态显示「取消/保存」——因此始终紧贴它所
作用的正文，而非混在管理操作（安装/启用/移除）之中。

## 编辑对象

编辑的是**原始文件**（含 frontmatter），而非渲染后的正文。这一点很关键：保存必须
逐字回写整个文件，而展示用的详情只带正文（frontmatter 已被解析出来给头部使用），
所以编辑器通过 `readSkillMd` 单独读取原始文本，并通过 `writeSkillMd` 写回。

## 保存

`write_skill_md` 通过后端的 `list` 解析技能名（因此不会有任何路径从前往后拼接），
并采用**原子写**：新内容先落到同目录的 `SKILL.md.tmp`，再重命名覆盖 `SKILL.md`，
因此写入中断绝不会留下半截文件。保存后会使详情缓存、原始文本缓存与已安装列表失效
——列表行的描述读取自文件，所以会随编辑一并刷新。

## 编辑器集成

编辑器是基于 `@uiw/react-codemirror` + `@codemirror/lang-markdown` 的 CodeMirror 6，
采用懒加载，只有真正开启编辑时才加载 CodeMirror 代码块。它复用应用已有的 shadcn
CSS 变量而非引入主题包，因此明暗主题随 `next-themes` 自动切换；功能裁剪为高亮、
历史与查找（不显示行号、折叠与自动补全）。

## 守卫与已知限制

- 编辑状态下 `←`/`→` 不会切换技能，`Escape` 不会关闭抽屉，因此只有显式的**取消**
  按钮才会丢弃草稿。
- 编辑时以其它方式关闭抽屉（点击遮罩）会丢弃草稿——没有未保存更改的确认提示。
- 应用外部对文件的并发修改不会被检测；后写入者生效。
- 非 Tauri 环境（浏览器开发服务器）下编辑内容保存在内存 mock 中，刷新即丢失。
